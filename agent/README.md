# 驾驶模拟器 AI 控制助手

一个集成在驾驶模拟器中的 AI 助手，让你通过**自然语言**控制仿真设备、调整车辆参数、分析实验结果。

## 产品简介

传统驾驶模拟器操作需要手动在多个面板之间切换，填写参数、下发指令、记录数据。过程中容易遗漏步骤，不同操作员的经验差异也会影响实验效率。

AI 助手将仿真操作的"专家经验"内置到了系统中。**你说"单移线侧倾太大，帮我分析一下"**，助手会自动查询当前车辆配置、检索领域知识库、给出调校建议，并询问你是否执行。

## 核心能力

### 1. 自然语言操控

用日常中文描述你想做的事，无需记忆参数名称或菜单路径。

**示例：**

> "把车型换成 SUV_baseline，前弹簧刚度降低 5%"

助手会翻译为具体操作、展示摘要、等待你确认后执行。执行结果会同步显示在 GUI 上。

### 2. 智能诊断与规划

遇到主观评价问题（"侧倾大"、"中心区手感重"、"起伏路面舒适性差"），AI 不会盲目调参，而是：

- 查询当前车辆配置和场景设置
- 检索内置的底盘调校知识库
- 生成包含参数方向、风险提示、验证指标的调校方案
- 等你确认后再逐步执行

### 3. 多步自动执行

复杂任务只需描述目标，AI 会拆解为多步操作并自动串联。例如：

> "帮我准备单移线测试场景，跑一次仿真，然后分析结果"

助手会自动：设置工况 → 确认场景 → 运行 CarSim → 跳转到分析页面。

### 4. 知识库积累

每次操作后，系统自动记录操作参数、工况条件和执行结果。有价值的经验可以保存为知识条目，供后续类似问题参考。知识库文件是中文 Markdown 格式，可直接用文本编辑器修改。

### 5. 操作安全保障

所有**会改变车辆状态或设备设置**的操作，执行前都会弹出确认对话框，显示操作摘要和风险提示。未匹配近期规划的操作会额外标注警告。

## 支持的操作领域

| 领域 | 可以做什么 | 示例 |
|------|-----------|------|
| **底盘调校** | 切换车型、调整弹簧刚度/稳定杆、查询悬架配置 | "把后稳定杆换成 BAR_STIFFER" |
| **触感力反馈** | 调节方向盘摩擦/阻尼/回正/限位/手感轻重 | "方向盘中心区太轻了，增加一点阻尼" |
| **场景设置** | 切换工况/地图/起点/路段，一键确认生效 | "把工况设成单移线，起点用默认的" |
| **仿真运行** | 运行 CarSim、打开 Simulink、编译 DSpace | "跑一下当前配置的仿真" |
| **数据记录** | 开始/结束记录、配置记录选项 | "开启自动记录，只记录 IMU 和 CarSim" |
| **运动平台** | 一键启停平台、设置位置偏置 | "平台复位，X 方向偏置 0.5 米" |
| **视觉补偿** | 设置运动跟随和延迟补偿参数 | "调整视觉延迟补偿为 20ms" |
| **报警监控** | 开启/关闭实时驾驶报警 | "帮我开启报警监控" |
| **结果分析** | 查看离线仿真对比、加载历史数据 | "分析上一组方案和基准方案的对比" |
| **知识库** | 检索调校原理、保存经验规律 | "为什么侧倾大要先调稳定杆而不是弹簧" |

## 快速上手

### 环境准备

AI 助手依赖本地 LLM 服务。首次使用需启动 llama-server：

```bash
llama-server --jinja -fa \
  -m /path/to/qwen2.5-coder-14b-instruct-q4_k_m.gguf \
  --host 127.0.0.1 --port 8080 -ngl 99 -c 8192
```

然后正常启动驾驶模拟器主程序：

```bash
python main.py
```

### 开始对话

1. 主窗口右下角状态栏点击 **"Toggle AI Assistant"** 按钮
2. 右侧弹出 AI 对话面板
3. 在输入框中输入指令，按 Enter 发送
4. AI 回复后，如需确认操作，在弹出的确认对话框中点击"确认执行"或"取消"

### 状态指示灯

对话面板顶部的指示灯显示 LLM 连接状态：
- **绿色** ●：LLM 服务正常连接
- **红色** ●：LLM 服务未连接

### 典型工作流

```
用户: "帮我看看单移线工况下侧倾为什么这么大"

AI:    [查询当前配置: SUV_baseline, 前弹簧 K=45, 后弹簧 K=40]
       [检索知识库: 侧倾问题诊断与调校]
       根据当前配置分析，建议以下方案:
       1. 前稳定杆从 BAR_DEFAULT 换为 BAR_STIFFER (+15%)
       2. 前弹簧刚度增加到 48 N/mm (+6.7%)
       预计侧倾角减小约 15-20%
       是否执行方案？

用户: "确认执行"          ← 弹出确认对话框，点击确认

AI:    ✅ 已选择前轮稳定杆: BAR_STIFFER
       ✅ 已设置前弹簧刚度为 48.0
       方案已执行完毕。建议运行仿真验证效果。

用户: "跑一下仿真"

AI:    ✅ CarSim 仿真已执行完成 (第 3 组方案)
       可以查看离线数据对比分析。
```

## 注意事项

- 操作确认对话框是独立窗口，如被遮挡可切换窗口找到它
- 关闭 AI 面板后再打开，若有待确认操作，对话框会自动恢复
- 输入"清空"可重置对话历史
- AI 最多连续执行 10 步，超过会自动停止
- 如果 LLM 响应超时或出错，系统会自动重试一次并压缩历史
